The official intent

Cranfield CRAN-0091 concerns resilient cognitive navigation with adaptive multisensor fusion for autonomous transport under degraded or unavailable GNSS. The official page lists a 30 September 2026 application deadline and 25 January 2027 start, checked 20 September. Eligibility and selection remain institutional decisions.

Existing work that supports preparation

Ubuntu/Python Tello perception, telemetry and event logging support experimental engineering. E012 monocular visual odometry and target-loss policies provide an inspected starting point; 13 offline policy tests passed in this portfolio review. HMM temporal evaluation and AIOS provenance offer transferable methods for sequential data and reproducibility.

These are adjacent capabilities, not proof of completed PNT research. The current monocular output is unscaled; calibrated inertial/radio fusion, navigation ground truth, timing integrity and GNSS-denial validation are not established. Wi-Fi/video degradation is a communication issue and must not be equated with demonstrated GNSS resilience.

Proposal alignment and document lineage

The existing application folder contains a personal statement for LLM human–swarm collaboration, while an archived navigation-focused draft also exists. Preserve both, but label their purposes correctly. A new navigation alignment brief is prepared separately; the previously submitted version and portal state are not changed.

Candidate research question: can reliability-aware sensor selection improve estimation accuracy and recovery under missing, biased and delayed observations while maintaining calibrated uncertainty? Start with robust statistical fusion; compare a learned reliability estimator only after a frozen data split and a justified baseline. This is a proposal hypothesis, not an established gap.

New runnable preparation experiment

A standard-library 1-D simulation compares a fixed-noise Kalman update with a 3-sigma innovation gate on the same 20 seeded scenarios. Mean position RMSE: fixed 1.2495, gated 0.1270, in synthetic units. The gated method has lower RMSE in 20/20 runs.

The scenario deliberately includes absent GNSS and biased radio measurements. It is an engineered illustration, not a trained AI model, real sensor evaluation or general performance claim. Ground truth is used only for scoring; tests check that changing truth cannot alter the estimates and future observations cannot alter a prefix.

Download the source bundle and run: python3 navigation_demo.py --output navigation-results.json. The source records fixed parameters, seeds, input hashes and per-run results.

Work needed to address the full research intent

1. Review navigation/fusion prior art and derive a defensible question. 2. Build a timestamped replay dataset with sensor calibration and independent truth. 3. Compare fixed, robust and learned fusion using identical splits and failure schedules. 4. Assess error, recovery time, covariance consistency, availability and runtime. 5. Test hardware-in-the-loop with suitable equipment and supervision.

The home lab can support initial software and perception work. Access to calibrated navigation sensors and suitable reference equipment is a research dependency. No airborne trial, active RF interference, admissions message or application submission is performed by this portfolio build.
