NotebookLM, hybrid RAG and governed AI agents

A local evidence pipeline combines NotebookLM source preparation, vector retrieval, graph relationships and advice-only agents. The AWS page is a reviewed demonstration of the design and measured runs; it is not presented as a live autonomous control plane.

Measured local work

The local vector RAG run ingested 218 documents into an FTS5/TF-IDF index, produced 219 chunks, and averaged 8.2 results across five test queries covering learning analytics, GPS-denied drones, the MSc metals work, actions and PhD research. The run reports PASS and records that no Drive bodies, Gmail bodies or OpenAI calls were read.

The graph layer contains 1,183 nodes and 3,095 edges, with project, topic, action and candidate-retrieval relationships. It reports PASS_WITH_WARNINGS because the graph is metadata-led and the Drive/Gmail bodies were not downloaded. The history-ingestion evidence records 47 conversations, 423 messages, 157 project links and 76 extracted actions.

NotebookLM and agent boundary

Drive contains NotebookLM staging folders, index queues, source packs and an MSc OULAD source brief. These are useful evidence-pack and research-notebook artefacts: they show source curation and hand-off into NotebookLM, not a continuously refreshed NotebookLM service owned by this portfolio.

Agentic RAG produces review recommendations only. The Four-C governance rules prohibit external writes, finance orders, drone commands and submissions; retrieved text is treated as untrusted evidence and outputs remain provisional until a human promotes them.

Hybrid architecture to complete

The next production-shaped step is a reproducible hybrid path: versioned source snapshots, a lexical/vector index, a graph projection for relationships, reranking with citations, freshness and sensitivity checks, then an approval queue. A scheduled refresh, independent restore check, evaluation set and public API are still required before calling this a live cloud service.

This separation lets the same evidence support the Air Marshal/CRAN research programme, the MSc learning-analytics work, financial research and the AIOS operating model without implying that historical logs are current autonomous operation.
