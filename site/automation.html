Cloud migration design — proposed, not deployed

Preserve Ubuntu as an optional development and robotics edge device. Move bounded scheduled captures first: EventBridge schedule to a scoped worker, private versioned S3 for source snapshots, validation and quarantine, then a reviewed public summary. Store provider credentials in a managed secret store.

Add failure queues, alarms, idempotency keys and an independent restore check before retiring local schedules. Deploy one workload at a time and measure cost. The current live AWS deployment is the static portfolio, not this operational architecture.

Robotics latency-sensitive control remains at the edge. AWS can store approved experiment summaries and run offline analysis; the public dashboard is not a remote drone-control endpoint.
